# Council Integration Protocol

## Purpose

Council is a strategic review capability.

It should be used when multiple independent perspectives are more valuable
than a single agent's judgement.

Council is not the default execution engine.

---

# 1. WHEN TO USE COUNCIL

Use Council when:

- multiple design directions compete
- several references are strong candidates
- the visual identity is uncertain
- the project may be becoming generic
- a rebuild strategy is unclear
- the design is high-risk
- the Gauntlet critic and builder disagree strongly
- a major architecture decision has significant tradeoffs
- final design quality is uncertain

---

# 2. WHEN NOT TO USE COUNCIL

Do not invoke Council for:

- obvious bug fixes
- deterministic tests
- simple CSS corrections
- file formatting
- routine implementation
- straightforward requirements

---

# 3. COUNCIL PERSPECTIVES

When appropriate, use perspectives such as:

- Creative Director
- Art Director
- UI/UX Designer
- Product Designer
- Frontend Architect
- Motion Designer
- 3D Designer
- Accessibility Specialist
- Performance Specialist
- Brand Designer

Only use perspectives relevant to the task.

---

# 4. COUNCIL QUESTION

The Design Loop should ask a precise decision question.

Bad:

"Is this website good?"

Good:

"Which hero direction produces the strongest premium real-estate identity while
remaining usable on mobile?"

---

# 5. EVIDENCE

Provide Council with:

- screenshots
- references
- requirements
- design constitution
- current design direction
- known constraints

Do not rely on unsupported claims.

---

# 6. OUTPUT

Council should return:

1. consensus
2. strongest disagreement
3. strongest option
4. major risks
5. recommendation
6. confidence

---

# 7. FINAL DECISION

Council is advisory.

The Design Loop remains responsible for:

- integrating the recommendation
- checking compatibility with requirements
- checking technical feasibility
- deciding whether to act

Do not blindly follow majority opinion.

---

# 8. GAUNTLET + COUNCIL

Use:

Council:
Which direction should we take?

Gauntlet:
Is the direction we chose actually strong enough?

This distinction should be preserved.

---

# END OF COUNCIL PROTOCOL
